# Imprimir os pedidos do dia

Dá para imprimir vários pedidos de uma vez, direto da agenda.

1. Marque o quadradinho dos pedidos que quer imprimir. Para marcar todos de uma lista, use **Selecionar todas para imprimir** no topo da lista.
2. No rodapé da tela aparece uma barra com a quantidade de pedidos selecionados.
3. Clique em <span class="botao">Imprimir</span>. O sistema gera um arquivo com todos os pedidos.
4. Para desmarcar tudo, clique em **Limpar** na mesma barra.

![Barra de impressão com 2 pedidos selecionados](/img/agenda/barra-impressao.png)

Você pode selecionar pedidos das duas colunas (Visitas do dia e Precisa de atenção) e imprimir tudo junto.

::: tip O que sai no pedido impresso
O texto do campo **Detalhes do serviço** sai no pedido impresso, no campo **Observações**. O campo **Observações** do cadastro do pedido é uma anotação interna e **não** é impresso.
:::

A mesma impressão em lote existe na [consulta de pedidos](../pedidos/consultar#_4-imprimir-varios-pedidos) e nos [pedidos de um cliente](../pedidos/por-cliente).
