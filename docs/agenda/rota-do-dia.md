# Organizar a rota do dia

O sistema sugere a ordem das visitas que faz o técnico rodar menos.

1. Na agenda, escolha o dia.
2. Clique em <span class="botao">Organizar rota de hoje</span> (ou **do dia**, se for outro dia). O botão só aparece quando há visitas no dia.
3. Confira no mapa a ordem sugerida.
4. Se quiser, aplique os horários sugeridos às visitas. A agenda é atualizada com os novos horários.

<!-- PRINT: janela da rota com o mapa e a lista de paradas -->

::: warning Atenção
A rota usa os endereços cadastrados nos pedidos. Se um endereço estiver incompleto, o ponto pode cair no lugar errado do mapa. Confira o endereço no pedido.
:::

::: tip
Só quem tem permissão para registrar visitas consegue aplicar os horários. Os outros usuários veem a rota, mas não alteram.
:::
