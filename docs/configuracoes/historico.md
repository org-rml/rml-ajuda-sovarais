# Histórico de registros

O Histórico de registros mostra quem criou, editou ou excluiu cada coisa no sistema, e quando. Em cada edição aparece o valor **antes** e **depois**.

::: info Na prática
No menu lateral, acesse **Configurações › Histórico de registros**. Também dá para abrir o histórico de um registro específico pelo link **Ver no histórico** (na consulta de clientes, por exemplo).
:::

![Histórico de registros](/img/config/historico.png)

## Filtros

| Filtro | Como funciona |
|---|---|
| **Período** | Datas inicial e final, ou os atalhos **Hoje**, **7 dias**, **30 dias** e **Este mês**. |
| **Usuário** | Mostra só o que uma pessoa fez. |
| **Cadastro** | Clientes, pedidos, produtos, serviços, usuários etc. |
| **Buscar** | Nome do registro, campo ou valor (ex.: PED-000021). |
| **Todas / Criou / Editou / Excluiu** | Tipo de ação. |

Os quadros no topo mostram o total de registros, criações, edições e exclusões no período. Clique num quadro para filtrar por ele.

## Lendo um registro

Cada linha traz a hora, quem fez, o que foi alterado e uma etiqueta (**Criou**, **Editou** ou **Excluiu**). Nas edições, a tabela mostra cada **campo** com o valor **antes** (riscado) e **depois**.

Os registros ficam agrupados por dia, do mais recente para o mais antigo.
