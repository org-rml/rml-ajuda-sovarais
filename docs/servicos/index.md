# Cadastro de serviços

O cadastro de serviços guarda o que a equipe faz e cobra: instalação, manutenção, visita para orçamento etc. Os serviços aparecem na busca de itens do [pedido](../pedidos/cadastrar).

**Neste artigo, você vai ver:**

1. [Consultar serviços](#_1-consultar-servicos)
2. [Cadastrar um serviço](#_2-cadastrar-um-servico)
3. [Editar, inativar ou excluir](#_3-editar-inativar-ou-excluir)

::: info Na prática
No menu lateral, acesse **Cadastros › Serviços**. A tela tem as abas **Criar** e **Consultar**.
:::

## 1. Consultar serviços

![Consulta de serviços](/img/servicos/consulta.png)

- **Busca:** por código ou descrição.
- **Status:** **Todos**, **Ativos** ou **Inativos**.
- Clique no título **Preço** para ordenar.

## 2. Cadastrar um serviço

Abra a aba **Criar** e preencha:

![Formulário de serviço](/img/servicos/formulario.png)

| Campo | Obrigatório | Para que serve |
|---|---|---|
| **Código** | Automático | Gerado pelo sistema ao salvar. |
| **Descrição** | Sim | Nome do serviço, com pelo menos 3 letras (ex.: Instalação de varal de teto). |
| **Preço** | Sim | Valor que entra no pedido. |
| **Status** | — | Ligado = ativo. Serviços inativos não aparecem na busca do pedido. |
| **Observações** | Não | Anotações internas (ex.: inclui furação e fixação). |

Clique em <span class="botao">Salvar</span>.

## 3. Editar, inativar ou excluir

Na aba **Consultar**, use os botões da coluna **Ações**:

- **lápis**: editar. Depois das mudanças, clique em <span class="botao">Atualizar</span>;
- **círculo cortado**: inativar (ou ativar de novo);
- **lixeira**: excluir.

::: tip
Prefira **inativar** um serviço que não é mais oferecido. Os pedidos antigos continuam mostrando o item.
:::
